# Images

Drop screenshots and board photos here, then uncomment (or add) the matching lines in the root [`README.md`](../../README.md).

Suggested filenames (keep them stable so README links don’t break):

| File | Content |
|------|---------|
| `board.jpg` | LilyGO T3 / LoRa32 board (front, antenna attached) |
| `board-back.jpg` | Optional: silkscreen / revision markings |
| `oled-today-with-cum-mock.png` | OLED **Today** page mock (linked from root README) |
| `oled-24h-sparkline-mock.png` | OLED **24h graph** page mock (linked from root README) |
| `ha-dashboard.png` | Home Assistant entity or Energy graph |

Design/exploration mocks (`oled-*-fault-*.png`, compare sheets, etc.) are optional and not linked from the README.

Prefer JPEG/PNG under ~1 MB each. Avoid photos that show a readable meter ID, LAN hostname, or other personal details.
